# Security Policy

## Supported Versions

Only the latest released minor version receives security fixes. Older versions should upgrade.

## Reporting a Vulnerability

Please **do not** open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/zexy2/izmir-mcp/security/advisories/new).
Include steps to reproduce, affected version, and impact. We aim to acknowledge reports within
7 days.
