I built İzmir MCP: a read-only Model Context Protocol server for İzmir open
city data. Live ESHOT buses, metro/İZBAN/ferry timetables, on-duty pharmacies,

## LinkedIn (EN)

İzmir MCP brings the city's open data sources together behind one MCP server.
Every response carries freshness metadata, and an unavailable source shows up
as a typed error instead of empty data. Feedback welcome. <link>

## Reddit (r/mcp, r/izmir)

**Title:** İzmir MCP: open city data (transit, pharmacies, water) for MCP clients
